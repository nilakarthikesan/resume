# Earlier resume website

A static resume page retained as earlier portfolio work. `index.html` contains the page content and styling.

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Open [http://localhost:8000](http://localhost:8000). The page reflects an earlier career stage; the [GitHub profile](https://github.com/nilakarthikesan) describes my current work.
